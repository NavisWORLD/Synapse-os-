# Synapse Flow v1

Synapse Flow v1 extends the original `.syn` workstation-intent format into a bounded state-oriented language while preserving every original instruction.

## State evolution

```text
SYNAPSE/1
state coherence = 0.40
let gain = phi

fn evolve(step)
    set coherence = clamp(coherence + step * gain, 0, 1)
end

repeat 4
    call evolve(0.10)
end

if coherence >= 0.90
    emit "coherent"
else
    emit "stabilizing"
end

emit round(coherence, 4)
assert coherence >= 0 and coherence <= 1
```

## Arithmetic

```text
SYNAPSE/1
let a = 20
let b = 22
emit a + b
assert a + b == 42
```

## Existing Synapse OS control syntax

```text
SYNAPSE/1
profile pulse
cosmos probe
service check NetworkManager
```

Run a saved program through the existing OS command:

```text
synapse apply program.syn
```

The runtime also exposes `parse_file`, `check_file`, `run_file`, `Runtime`, `SafeExpression`, and `repl` as Python APIs for editor and tooling integrations.

See `SPEC.md` for the complete v1 contract and limits.
