# Synapse Flow v2

Synapse Flow v2 is the compiled, statically checked evolution of the `.syn` language used by Synapse OS.

## Execution target

`.syn` source -> type checker -> optimized `.synb` bytecode -> Synapse VM

A scalar C11 native backend has also been implemented and tested in the v2 overlay, but the connected GitHub write path currently refuses that backend file. It is intentionally kept out of this branch rather than hidden or obfuscated to bypass the guard.

## Core language

```text
SYNAPSE/2
state coherence: float = 0.25

fn evolve(step: float) -> float
    return clamp(coherence + step * phi, 0.0, 1.0)
end

repeat 3
    set coherence = evolve(0.2)
end

if coherence > 0.5
    emit "awake"
else
    emit "quiet"
end
```

Static types: `int`, `float`, `bool`, `str`, `none`, `list`, `map`, and explicit escape-hatch `any`.

Statements include typed `let` and `state`, `set`, `if/else`, `while`, bounded `repeat`, `break`, `continue`, typed `fn`, `return`, `emit`, and `assert`.

## Compiler commands

```bash
synflow check app.syn
synflow compile app.syn -o app.synb
synflow run app.synb
synflow disasm app.synb
synflow debug app.syn --break-line 12
synflow lsp
```

## Network and AI capabilities

Network access is denied by default. A program must be launched with `--net` and at least one explicit host grant:

```bash
synflow run agent.synb --net --allow-host api.example.com
```

Builtins: `http_get`, `http_json`, `http_post_json`, `dns_lookup`, `tcp_probe`, and `ai_chat` for OpenAI-compatible chat-completions endpoints. API tokens are read from a named environment variable at runtime and are not embedded in bytecode.

## Package protocol

A package contains `synapse.toml` with `[package]` metadata and optional `[dependencies]`. The registry client consumes an HTTPS JSON index. Every downloadable archive must provide a SHA-256 digest and is checked for archive path traversal before installation.

There is not yet a public hosted Synapse registry. The client, manifest, cache, integrity checks, and registry protocol are implemented so a hosted registry can be added without changing the language format.
