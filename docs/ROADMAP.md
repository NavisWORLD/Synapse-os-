# Roadmap

## 0.1 Nebula
- reproducible live-build recipe
- Plasma desktop and Calamares installer
- Synapse control plane, telemetry, COSMOS probes
- safe performance profiles, zram, docs, SDKs

## 0.2 Photon
- hardware capability database
- measured boot/app/audio latency dashboard
- first-boot onboarding and visual theme package
- optional COSMOS installer/attachment package

## 0.3 Pulsar
- signed package repository
- Secure Boot-aware build pipeline
- optional tuned kernel flavor only if benchmark evidence supports it
- ARM64 image path

## 1.0
- signed releases, upgrade channels, rollback story, hardware certification matrix, installer branding, automated integration tests on real hardware classes
