# Synapse OS // Apple Intel

Target: pre-T2, non-Touch-Bar Intel MacBook Pro hardware from the 2014-2015 generation.

This folder is additive to the existing Synapse OS amd64/GENESIS flow. It provides Apple hardware detection, read-only preflight/diagnostics, guarded install launchers, EFI recovery, and an experimental `.app` inspection bridge.

Physical certification is **not** claimed until a real Mac completes live boot, hardware acceptance, installation to the wiped internal disk, and cold boot.
