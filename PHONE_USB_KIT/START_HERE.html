1. Download on the phone

Download SynapseOS-Phone-USB-Kit.zip and every file matching:

SynapseOS-Nebula-amd64.iso.part-*

Keep the part files together and do not rename them.

2. Move the folder to USB storage

Using the iPhone Files app, you can move the downloaded kit and ISO parts onto an external USB drive for storage/transfer.

Important: copying files onto a USB does not make the USB bootable. A bootable installer requires the reconstructed ISO to be written as a raw disk image. Ordinary iPhone Files app copying cannot replace that flashing step.

3. Reconstruct and verify

On Windows run reassemble-usb-installer.ps1. On macOS/Linux run reassemble-usb-installer.sh.

The helpers verify every part and rebuild:

SynapseOS-Nebula-amd64.iso

4. Flash, then boot

Flash the reconstructed ISO with Rufus, balenaEtcher, or the documented raw dd method. Then insert that flashed USB into the target amd64/UEFI machine and boot the USB entry.

For the ASUS CX1700CKA / GALLOP target, legitimate supported UEFI preparation is still required before booting Synapse/GENESIS.
